## 📷 Готовый камера-менеджер для сервера RAGE:MP

Легкое взаимодествие камерами - создавайте камеры, управляте, анимируйте их плавно с разными параметрами.

## 📦 Установка

Скопируйте данный код, создайте файл в клиент-папке (например, `client_packages/client/cameraManager.ts`);
Импортируйте этот файл в `client_packages/index.ts` : `import './client/cameraManager.ts`.

# 🛠 Использование

```typescript
const camera: CameraAnimation = new CameraAnimation(); // создание экземпляра камеры

camera.create(new mp.Vector3(100, 200, 300), [0, 0, 0, 0], 60); // создание камеры
camera.setPos(new mp.Vector3(100, 200, 300), [0, 0, 0, 0]); // поставить позицию камере
camera.destroy(); // удалить камеру

const animation: AnimateData = { // переменная которая хранит информацию о анимации
    "position": [400, 500, 200], // конечная позиция (она будет анимироваться от коордит, на которых находится сейчас)
    "rotParams": [0, 0, 0, 0],  // параметры
    "duration": 1500 // время анимации в мс.
};

camera.goAnimate(animation); // запустить анимацию для камеры, с нашими параметрами в переменной
```
